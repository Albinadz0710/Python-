# Проект автотестов с использованием PageObject и Allure

## Описание проекта
Проект содержит UI-тесты (для интернет-магазина и калькулятора), написанные на Python с использованием фреймворка `pytest` и паттерна `PageObject`. 
Для генерации наглядных и подробных отчетов используется фреймворк `Allure`.

## Установка зависимостей
Перед запуском тестов убедитесь, что у вас установлены все необходимые библиотеки. Откройте терминал в корне проекта и выполните команду:

```bash
pip install -r requirements.txt
pip install allure-pytest
